# Cyber Portfolio
npm install && npm run dev   |   npm run build   |   npm run preview
كل البيانات (الاسم، الصورة، الألوان، السوشيال، المشاريع، التواصل) في: src/config/site.ts
لتغيير الصورة: ضع ملفك في public/ وعدّل avatar في الإعدادات.
النشر على GitHub Pages: Settings → Pages → Source = GitHub Actions، ثم ارفع المشروع على فرع main.
تأكد أن base في vite.config.ts يطابق اسم المستودع.
